A set of hands-on notebooks introducing statistical modeling and machine learning
through astronomical examples: dimensionality reduction, linear and logistic
regression, a small neural network, and Gaussian processes (both as a regression
tool and as a cosmological emulator). Each notebook is self-contained and runs on
the data files included in this directory.

### 1. Dimensionality reduction — PCA
`Dimension_reduction_PCA.ipynb`

PCA applied to a set of SDSS quasar spectra. Compute the eigenspectra, project the
data onto them, and use the decomposition for reconstruction and denoising
(spectrum ≈ eigenvectors × coefficients), explore the coefficient space, and use
the low-dimensional coefficients for classification. A concrete look at why
high-dimensional spectra live on a low-dimensional manifold.

### 2. Logistic regression
`Logistic_regression.ipynb`

A from-the-ground-up binary classifier separating quasars from stars using SDSS
colors (u−g, g−r, r−i, i−z). Covers the train/validation/test split, the logistic
model and its sigmoid decision function, and evaluation with completeness (recall)
and purity (precision).

### 3. Neural networks in PyTorch
`Neural_network_train_val_test.ipynb`

Two parts sharing one fit → predict → evaluate loop:
- **Linear regression** — fit Hubble's law, v = H₀·d, to the classic
  distance–velocity data.
- **Classification** — a small fully-connected network for QSO vs. star, with the
  test file held out untouched and an 85/15 train/validation split carved from the
  training file.

### 4. Gaussian process regression — stellar light curve
`gaussian_process_stellar_light_curve_exercise.ipynb`

Reconstruct an unknown, irregularly sampled stellar light curve from noisy
observations with a GP. Walks the full chain from kernel to covariance matrix to
prior samples to the posterior predictive, then uses the posterior to decide where
to observe next and to compare kernel choices. Companion slides:
`GaussianProcess_final.pdf`.

### 5. Gaussian process emulator — halo mass function
`GP_emulator_exercise.ipynb`

Build a fast surrogate for an expensive cosmological calculation. Using
[Dark Emulator](https://dark-emulator.readthedocs.io/) as the "expensive
simulation," train a GP to predict the halo mass function as a function of
cosmological parameters (varying Ω_m and ln A_s). Introduces Latin Hypercube
Sampling for training-set design and evaluates emulator accuracy.

## Setup

The notebooks run on Google Colab or a local Python environment.

**Local environment**
```bash
pip install numpy scipy matplotlib astropy scikit-learn torch
pip install dark_emulator   # only needed for GP_emulator_exercise.ipynb
```

**Google Colab**

Upload the notebook and the relevant `.fits` files, or mount your Drive. A few
notebooks include a `google.colab` drive-mount cell; adjust the paths to wherever
you place the data.

Python 3.9+ is recommended. `dark_emulator` is only required for the emulator
notebook; everything else runs with the standard scientific-Python stack plus
PyTorch.
